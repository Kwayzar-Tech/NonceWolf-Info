# NonceWolf

NonceWolf is a Bitcoin Stratum mining proxy for Windows and Mac, made for home miners and small farms. Block rewards go to the operator. There are no hidden fees.

A free 7-day trial is available. A lifetime license is $99. Buy at [NonceWolf.com](https://noncewolf.com).
